# Upsight

> Upsight was a mobile analytics and marketing ("user lifecycle management") platform for apps and games, offering omnichannel analytics, integrated web and mobile marketing, ad optimization, and a DataMine SQL analytics product, all integrated through a single SDK for iOS, Android, tvOS, Unity, and Web. The company was a Battery Ventures portfolio company. The platform is now defunct: upsight.com no longer resolves (nameservers parked at registrar defaults), the help.upsight.com documentation host is offline, and the GitHub org has been dormant since 2020.

This file was generated by the API Evangelist enrichment pipeline on 2026-07-21 from live probes and public archives. There is no live API surface to integrate with; the links below are the surviving public artifacts.
